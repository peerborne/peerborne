# Peerborne pinning node goals

A proposal for a Peerborne pinning/backbone node.

## Goals

- To have pinnable groups of Peerborne peers.
- To have bootstrap nodes for private swarms.
- To incentivise pinning of peers via asset reward (think filecoin)

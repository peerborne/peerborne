Build the repository with the [source quick start](../quick-start/) first. The
eleven `@peerborne/*` packages are unpublished workspaces. Use these files in a
browser React/TypeScript workspace with `@peerborne/core`,
`@peerborne/automerge`, `@peerborne/react`, React, and React DOM available.
Automerge's browser build also needs Vite's WASM setup; the
[wiki example configuration](https://github.com/Peerborne/peerborne/blob/main/examples/wiki-swarm/vite.config.ts)
shows the required plugins. This is a local document exercise, with no relay or
second identity required.

This exercise creates a fresh, non-extractable signing key on every page load.
A reload therefore creates a **new identity**. Before building a persistent
application, design storage for the signing identity, document keys, and KEM
state separately; see [Identities](../../concepts/identities/). A document path
alone does not give another client its keys or access.

Click **Name this workspace**. The button becomes **Ready to ship** after the
document subscription updates. The node starts once, outside the React render
lifecycle.

`change` currently returns `void` and drops mutation rejections. This compact
component demonstrates the subscription API; use
`await document.change(...)` with application error handling when a save action
must report authorization, storage, or publication failures. See the
[React integration guide](../../cookbook/react/) for lifecycle details.

## Connect another client

Pass your relay's dialable multiaddr to `defaultBootstrapConfig` instead of an
empty list; see [Run your own relay](../../cookbook/running-a-relay/). An empty
bootstrap list creates a local node with no configured bootstrap peers.
Connecting does not onboard a new identity. Use the current
[signed invitation flow](../../cookbook/invitations/) to share with one online
collaborator, and review its membership and recovery limits.

The component, setup, and entry point are stored as source files and checked
together against the workspace APIs:

```sh
yarn build
node site/scripts/check-doc-snippets.mjs
```

For a runnable browser application, follow the [source quick start](../quick-start/).
